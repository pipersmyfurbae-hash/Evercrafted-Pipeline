# How to Use These Documents

---

## The Three Files

| File | When to paste | How often it changes |
|---|---|---|
| EVERCRAFTED_CONTEXT_BLOCK.md | Start of EVERY conversation | Rarely — only if a brand or major architecture changes |
| EVERCRAFTED_PROJECT_STATE.md | Start of every conversation | After every session — update render status and what's next |
| EVERCRAFTED_LOCKED_RULES.md | Any session involving renders, blueprints, or design | Never — these are permanent |

---

## The 5-Minute End-of-Session Update

At the end of each working session, spend 5 minutes updating EVERCRAFTED_PROJECT_STATE.md:

1. Check off anything completed in the render status table
2. Update "What's In Progress" with current phase and any learned parameters
3. Move completed items from "What Comes Next" to "What's Locked"
4. Add any new "Decisions Already Made" to the locked list

That's it. Five minutes prevents the loop from starting again.

---

## How to Start a Session

**Paste in this order:**
```
[EVERCRAFTED_CONTEXT_BLOCK contents]

[EVERCRAFTED_PROJECT_STATE contents]

Then describe what you want to work on today.
```

**For render/design sessions, also add:**
```
[EVERCRAFTED_LOCKED_RULES contents]
```

---

## The Rule

If you find yourself explaining something you've already explained before — stop. That information belongs in the Project State card. Add it there once. Paste it next session. Never explain it again.
